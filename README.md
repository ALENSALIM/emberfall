Emberfall is a lantern-keeper survival arcade game: keep your lantern burning, gather embers to feed it, and hold the valley against the shadow wisps until dawn breaks on the tenth night. A flare costs fuel but drives the wisps back — spend it well.

## Run it

```sh
cd game && python3 -m http.server 8080
# open http://localhost:8080 in desktop Chrome
```

WASD or arrow keys to walk, Space or click to flare, P to pause, M to mute, R to restart.
